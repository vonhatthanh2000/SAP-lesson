Managed or unmanaged?

Managed

Prefer for a new BO whose CRUD and persistence fit RAP conventions. RAP supplies standard transactional buffering and save behavior; implement domain-specific breakouts.

Unmanaged

Use when an existing transactional implementation or persistence mechanism must remain authoritative. You assume more of the RAP provider contract.

Hybrid breakouts

Use unmanaged/additional save when managed interaction semantics fit but persistence or follow-up processing requires a controlled seam.

Primary source: SAP Help — Business Object Implementation Types.

Three distinctions interviewers probe

  • Authorization ≠ feature control: user permission versus current instance capability.
  • Business behavior ≠ service exposure: the BO owns rules; service artifacts expose it.
  • Transactional buffer ≠ database: requested changes are not durable until the save contract succeeds.
