Two contracts, one topology

ContractOwnsMust not own
Interface CDS model Keys, fields, semantic relationships, composition topology, and reusable associations. A single UI's layout or accidental public surface.
Projection CDS model A consumer-specific subset, aliases, value-help/text enrichment, and redirected projected navigation. Persistence ownership or business invariants.

A projection is not a copied data model. It is a controlled view of the base model. If the aggregate boundary is wrong, another projection cannot repair it.

Interface entities: express ownership and semantics

Use these as design skeletons. Replace table and reference-entity names with artifacts available in your system. 

define root view entity ZR_SalesOrderRequest
  as select from zsor_request as Request
  composition [0..*] of ZR_SalesOrderItem as _Item
  association [0..1] to ZI_CustomerReference as _Customer
    on $projection.SoldToParty = _Customer.CustomerID
{
  key Request.request_uuid         as RequestUUID,
      Request.sold_to_party        as SoldToParty,
      Request.status               as Status,

      @Semantics.amount.currencyCode: 'TransactionCurrency'
      Request.total_amount         as TotalAmount,
      Request.transaction_currency as TransactionCurrency,

      _Item,
      _Customer
}
define view entity ZR_SalesOrderItem
  as select from zsor_item as Item
  association to parent ZR_SalesOrderRequest as _SalesOrderRequest
    on $projection.RequestUUID = _SalesOrderRequest.RequestUUID
  association [0..1] to ZI_ProductReference as _Product
    on $projection.Product = _Product.ProductID
{
  key Item.item_uuid            as ItemUUID,
      Item.request_uuid         as RequestUUID,
      Item.product              as Product,

      @Semantics.quantity.unitOfMeasure: 'QuantityUnit'
      Item.requested_quantity   as RequestedQuantity,
      Item.quantity_unit        as QuantityUnit,

      @Semantics.amount.currencyCode: 'TransactionCurrency'
      Item.unit_price           as UnitPrice,
      @Semantics.amount.currencyCode: 'TransactionCurrency'
      Item.net_amount           as NetAmount,
      Item.transaction_currency as TransactionCurrency,

      _SalesOrderRequest,
      _Product
}

The annotations link an amount to its currency and a quantity to its unit; they do not calculate values. SAP's amount and quantity guidance defines these semantic contracts.

Activation can expose the circular-looking topology: the child needs an association to its parent, and the root then composes the child. Follow your ADT release's activation workflow rather than deleting one side of the final model.

Projection entities: preserve navigation, narrow exposure

@Metadata.allowExtensions: true
define root view entity ZC_SalesOrderRequest
  provider contract transactional_query
  as projection on ZR_SalesOrderRequest
{
  key RequestUUID,
      SoldToParty,
      Status,
      TotalAmount,
      TransactionCurrency,
      _Item : redirected to composition child ZC_SalesOrderItem,
      _Customer
}
define view entity ZC_SalesOrderItem
  provider contract transactional_query
  as projection on ZR_SalesOrderItem
{
  key ItemUUID,
      RequestUUID,
      Product,
      RequestedQuantity,
      QuantityUnit,
      UnitPrice,
      NetAmount,
      TransactionCurrency,
      _SalesOrderRequest : redirected to parent ZC_SalesOrderRequest,
      _Product
}

Redirection keeps navigation inside the projected graph: projected orders navigate to projected items, and projected items navigate back to the projected parent. The base entities remain the reusable BO model.
